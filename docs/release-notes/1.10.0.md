# Zocial 1.10.0

## ✨ Features

- **Pick your interface language, in the app.** A new **Settings → General → Interface language** dropdown (and a language picker on the login screen, before you log in) lets you choose between English, German, Spanish, French and Russian. The change applies **instantly — no page reload**.
- **One build, every language.** Languages are no longer baked in at build time. Every build now ships *all* languages, so the same image works for everyone and you can switch whenever you like.
- **Always sensible defaults.** The app starts in English, and any individual text that isn't translated yet falls back to English automatically — the UI is never left blank.
- **Dates, numbers and times follow your language too.** Relative times ("3 minutes ago"), join dates, counts and list formatting now use your selected language, not a fixed build language.

## 🔧 Changed / Removed

- **The `LOCALE` build variable is gone.** It used to bake a single language into the build (e.g. `LOCALE=de`). It's been removed completely — there's no `--build-arg LOCALE` anymore, and you can drop it from any `compose.yaml`, `.env`, CI workflow or build script. Language is now a runtime choice, so nothing needs rebuilding to change it.

## 🧹 Internal / Architecture

- New runtime i18n layer: all locale tables bundled, a runtime resolver with a strict *selected → English → key* fallback chain (so a missing or empty translation can never crash a render or show `undefined`), and a reactive `messages` map that templates use directly.
- Live-language reactivity was wired across every script-side label that previously froze at the boot language (breadcrumbs, page titles, status headers and toolbars, follow buttons, list/empty-state messages, settings labels, and the compose/settings dropdown configs).
- Deliberate, documented exceptions that stay English-on-mount: the emoji picker (a separate web component with its own data/cache) and a few dialogs that re-mount each time they open. See Architecture Handbook §15 and §20 for the full mechanics, challenges and trade-offs.

## 🔐 Security

- No security-relevant changes in this release.
