# Zocial 1.12.0

> **Draft — work in progress.** Rolls up the `1.11.x` development line (everything since the **1.11.0** release). New work lands as internal `1.11.1`, `1.11.2`, … dev patches and ships together here as `1.12.0`. Finalise the date and summary when the release is cut.

---

## ✨ Features

- **See a list's members (from 1.11.3).** The Manage-lists page now has a **Members** link for each list that opens an overview of everyone in it — laid out like the Follows/Followers pages, with the same **follow/unfollow** button on each person.
- **Push notifications show the sender's avatar (from 1.11.2).** OS push notifications already used the avatar of the account that triggered them; they now fall back to the Zocial app logo when no avatar is available, so a notification never shows the browser's blank default icon.

---

## 🐛 Fixes & robustness

- **Faster recovery when a list or hashtag feed hangs on a cold load (from 1.11.1).** The first attempt at a slow list/tag feed now gives up at the normal ~20 s timeout and retries once with the full headroom, instead of waiting the long timeout twice — so a stuck feed falls back to cached/empty in about 60 s instead of 80 s, while a genuinely slow-but-working server still gets the full time on the retry.

---

## 🧹 Internal

- **Code cleanup (from 1.11.2).** Consolidated three redundant timeline-cache-purge helpers into one and removed a now-redundant database scope option — no behaviour change.

---

## 🔐 Security

- No security-relevant changes so far.
