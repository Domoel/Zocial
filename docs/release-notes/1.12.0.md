# Zocial 1.12.0

*Released 2026-09-23.* This release focuses on **accessibility** and **lists**: tabs can now be reordered from the keyboard with screen-reader feedback, and every list gets a members overview with follow/unfollow. It also makes cold list/hashtag loads recover faster and makes the emoji data source robust against short outages. It rolls up everything since the 1.11.0 release.

---

## ✨ Features

- **Reorder navigation tabs with the keyboard (accessibility, from 1.11.4).** Tabs could previously only be reordered by dragging, which is unusable with a screen reader. Now, with a tab focused, **Alt+Shift+←/→** moves it, and your screen reader announces the new position ("Local — position 2 of 6"). The shortcut is listed in the keyboard-help dialog. When you browse the navigation with a screen reader, the tab name is read first and the shortcut hint after it (from 1.11.6). Requested and tested by a blind user — thank you!
- **See a list's members (from 1.11.3).** The *Manage lists* page now has a **Members** link for each list. It opens an overview of everyone in the list, laid out like the Follows/Followers pages, with the same **follow/unfollow** button on each person. On phones, the Members / Rename / Delete buttons now sit on their own line below the list name, so long names stay readable.
- **Push notifications never show a blank icon (from 1.11.2).** OS push notifications show the avatar of the account that triggered them. When no avatar is available, they now fall back to the Zocial app logo instead of the browser's blank default icon.

---

## 🐛 Fixes & robustness

- **Faster recovery when a list or hashtag feed hangs on a cold load (from 1.11.1).** When a list/tag feed is opened blank or with only cached posts, the first attempt now gives up at the normal ~20 s timeout and retries once with the full headroom, instead of waiting the long timeout twice. A stuck feed falls back to cached/empty in about 60 s instead of 80 s, while a slow-but-working server still gets the full time on the retry. Loading more posts at the bottom of a list keeps the full timeout (fixed in the pre-release review).
- **No stray errors when the emoji set is briefly unreachable (from 1.11.5, completed in the pre-release review).** If the emoji data can't be loaded for a moment (e.g. during a server deploy or on a flaky connection), emoji tooltips, emoji search and reactions now quietly skip instead of surfacing an unhandled error in the console. A background update check that fails is simply retried on the next page load, and a failed first-time download is retried automatically after 30 seconds.
- **The "Follow" button for hashtags is disabled until you type a tag**, matching the "Create list" button on the Manage-lists page.

## 🐳 Deployment

- **Images now come from the Gitea container registry:** `git.ztfr.eu/dome/zocial:latest` (production), `:dev` (development) and a fixed tag per release (e.g. `:1.12.0`). They are built automatically on every push. Docker Hub (`domoel/zocial`) is kept only as a manual backup, so switch your `image:` line if you pull from Docker Hub.
- **`docker/docker-compose.yaml` now pulls from the Gitea registry**; `docker/.env.example` and the `PORT` variable are unchanged.
- **New Synology project in `deploy/synology/`** (compose file + `example.env`, host port `ZOCIAL_PORT`) with automatic updates via Watchtower; see `deploy/README.md`.
- **Fixed the image build** (it failed on Alpine after a new pnpm major release): pnpm is now pinned to the project's `packageManager` version.

## 🧹 Internal / Code-review results

- **Pre-release review of the whole 1.11.x line** found and fixed two issues before they shipped: the faster cold-load timeout from 1.11.1 was also applied to "load more" at the bottom of lists and hashtags (where no retry follows), and the emoji fix from 1.11.5 didn't catch the error it was meant to (the emoji library runs its update check in the background, out of reach of the original fix). Both are fixed as described above.
- **Code cleanup (from 1.11.2).** Three redundant timeline-cache-purge helpers were consolidated into one, and a now-redundant database scope option was removed. No behaviour change.
- **Documentation.** The Architecture handbook was restructured: Lists now have their own section, the design-decisions log has a topic index, and the code-review log notes that its entries are point-in-time records. It also documents the emoji data-source handling (§10) and this release's review (§23).
